CartOS 0.1.28 — Installation Guide

CartOS is a cartridge-style game browser for OnionOS handhelds. This release
includes the v0.1.27 Optional features and updates the text background and
cached game catalog. It has been tested on the Miyoo Mini V4.

The ZIP includes the ready-to-use CartOS app, source code, and license notices.
You only need the App/CartOS folder for a normal installation. The optional
CartOS boot-and-GameSwitcher hook is in Startup/CartOS.sh. A separate restore
script is in Return/Restore-OnionOS.sh.

========================================================
BEFORE YOU START
========================================================

Shut down the handheld before removing its SD card. On the computer, open the
card partition that contains the App and Roms folders. The card may have a
different name or drive letter on each computer; identify it by its folders.

========================================================
INSTALL CARTOS
========================================================

1. Extract the CartOS ZIP on your computer.
2. Copy the App/CartOS folder from the extracted ZIP into the App folder on
   the SD card. The finished path should be App/CartOS, alongside the other
   OnionOS apps.
3. Safely eject the card, return it to the handheld, and turn it on.
4. Open Apps and choose CartOS. If it is not listed, use OnionOS's app refresh
   option or restart the handheld.

========================================================
UPDATE AN EXISTING INSTALLATION
========================================================

Before replacing App/CartOS, copy settings.ini, any BG*.png files you want
to keep, and recent-history.txt (if present) to your computer. Copy the new
App/CartOS folder to the card, then put those files back inside it. If you are
updating from an older build that used list-order.txt, copy that file into the
new App/CartOS folder for the first launch; CartOS imports its order into
settings.ini automatically. ROMs, saves, and collections are stored separately
from the CartOS app folder.

The game catalog and artwork indexes in App/CartOS/cache are temporary. You do
not need to copy them; CartOS rebuilds missing or invalid cache files.

The optional Startup/CartOS.sh and Return/Restore-OnionOS.sh are unchanged from
v0.1.25. If you already use that working hook, no script update is needed. If
your hook is older, replace .tmp_update/startup/CartOS.sh with CartOS.sh from
the ZIP's Startup folder. It adds the power-off game-resume fix and
updates the existing runtime hook in place. The hook is stored outside
App/CartOS, so updating the app folder alone does not update it. After
replacing the script, start the handheld once so it can update the runtime
hook, then restart once more to load the change. See SHOW HIDDEN FILES below.

========================================================
SHOW HIDDEN FILES
========================================================

The .tmp_update folder is hidden. Enable Show hidden files to view and open it
when setting up or removing the optional startup hook.

macOS:

- In Finder, select the SD card and press Command-Shift-period to show hidden
  files. Press the same keys again to hide them.

Windows 11:

- In File Explorer, choose View > Show > Hidden items. Also turn on File name
  extensions if you need to check the .sh filename.

Windows 10:

- In File Explorer, open the View tab and check Hidden items.

Linux:

- In the file manager, press Ctrl-H to show hidden files. Press Ctrl-H again
  to hide them.

========================================================
OPTIONAL: START CARTOS ON BOOT AND RETURN FROM GAMESWITCHER
========================================================

This optional hook starts CartOS automatically and returns to it after you
leave GameSwitcher. It leaves a game or app already queued by OnionOS alone.
To enable both features:

1. Enable Show hidden files using the instructions above.
2. On the SD card, open .tmp_update/startup. If startup does not exist, create
   a folder named startup.
3. From the extracted ZIP's Startup folder, copy CartOS.sh into that folder.
   The final path on the SD card should be .tmp_update/startup/CartOS.sh.
4. Safely eject the card and start the handheld. CartOS starts if OnionOS has
   no game or app queued. The script adds a marked GameSwitcher return hook to
   runtime.sh; it does not replace the runtime file.
5. Restart the handheld once more so OnionOS loads the updated runtime. After
   that, leaving GameSwitcher returns to CartOS.

OnionOS runs scripts in .tmp_update/startup during startup. The first start
adds the runtime change on the SD card; the next start loads it. Startup-script
support was introduced in OnionOS 4.3. If the script does not recognize the
runtime layout, it leaves runtime.sh unchanged, does not queue CartOS, and
records the reason in .tmp_update/logs/cartos-runtime-hook.log.

To turn both features off while keeping CartOS installed, shut down the
handheld and remove the SD card. Delete .tmp_update/startup/CartOS.sh. Copy
Return/Restore-OnionOS.sh from the ZIP into .tmp_update/startup, then return
the card to the handheld and start it. The restore script removes CartOS's
marked runtime change, removes itself, and clears CartOS's queued boot launch.
CartOS remains available from Apps. No full-card backup or runtime backup is
needed for this install or restore.

========================================================
CUSTOM BACKGROUNDS
========================================================

Copy a PNG image into App/CartOS and name the default BG.png. You can add
multiple backgrounds with names such as BG_(Forest).png or BG_(Space).png.
The name in parentheses appears in CartOS Settings under Background. Move to
Background and press left or right to choose an image, or choose NONE for a
black background. For the best fit, use the device's native screen resolution:

- Miyoo Mini V4 with OnionOS 560p support: 752 × 560 pixels.
- Miyoo Mini V1-V3 or Miyoo Mini Plus: 640 × 480 pixels.
- For another device running a compatible OnionOS build, use that device's
  native screen resolution.

CartOS scales the background to fill its display without distorting it. If the
image's proportions differ, CartOS crops a little from the center, so keep
important details away from the edges. The DEFAULT option uses BG.png; named
backgrounds are loaded from the same App/CartOS folder. After adding or
removing an image, press X in CartOS Settings to rescan backgrounds.

For light backgrounds, use Invert text colour in CartOS Settings to switch the
main browser text to a darker palette. Hide game title removes the large game
title from the browser. Text background adds a padded black backing at 90%
opacity behind interface text. When both Text background and Invert text colour
are enabled, the backing switches to translucent white for contrast. This
does not change the wallpaper or the search keyboard panel.

========================================================
MULTIPLE ARTWORK IMAGES FOR A GAME
========================================================

CartOS uses the usual OnionOS image first. To add one extra PNG image for a
game, place it in that system's Imgs/CartOS folder using the ROM title without
its extension.

For example, for Roms/GBA/Pokemon Emerald.gba, the extra image would be:
Roms/GBA/Imgs/CartOS/Pokemon Emerald.png

To add more extra images for the same game, add " - " and a view name before
the PNG extension:

Roms/GBA/Imgs/CartOS/Pokemon Emerald - Backcover.png
Roms/GBA/Imgs/CartOS/Pokemon Emerald - Boxart.png
Roms/GBA/Imgs/CartOS/Pokemon Emerald - Gameplay.png

For a ROM inside a subfolder, keep that ROM subfolder under Imgs/CartOS. For
example, Roms/GBA/RPG/Example.gba uses:

Roms/GBA/Imgs/CartOS/RPG/Example - Backcover.png
Roms/GBA/Imgs/CartOS/RPG/Example - Gameplay.png

The ROM title before " - " must match the ROM filename without its extension.
The plain filename without a suffix is also accepted as one extra image.
CartOS also reads the earlier per-ROM folder layout, such as
Imgs/CartOS/Pokemon Emerald.gba/Backcover.png. If two ROMs in the same folder
have the same title but different extensions, use that folder layout to keep
their artwork separate.

CartOS shows the normal OnionOS image first, then the plain-title image if
present, followed by labelled images in alphabetical filename order. If no
normal image is present, it starts with the first available extra image.
CartOS can display up to 20 images for one game.

While the cartridge is enlarged in the first launch step, press Left or Right
to browse images. Press A to continue to launch, or B to return to the game
list. Double-tap A from a game list to launch directly without stopping at the
image preview. In the main browser, START also launches in one press using the
same animation.

========================================================
UNINSTALL CARTOS
========================================================

1. Shut down the handheld and remove the SD card.
2. Open the card partition containing the App folder.
3. If you enabled the boot-and-GameSwitcher hook, enable hidden files and
   restore OnionOS first as described in OPTIONAL: START CARTOS ON BOOT AND
   RETURN FROM GAMESWITCHER. Start the handheld once to run the restore script,
   then shut it down and remove the SD card again.
4. Delete App/CartOS.
5. Safely eject the card, return it to the handheld, and turn it on.

Deleting App/CartOS does not remove game ROMs or save files; those are stored
elsewhere on the card. The restore script removes only CartOS's marked change
from runtime.sh; it does not restore a backup. Only remove the specific CartOS
files named above from .tmp_update; leave all other files and folders there
untouched.
